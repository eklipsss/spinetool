# Метрики итоговых структурных векторов

Этот документ описывает переменные, которые сохраняются в итоговые табличные векторы признаков:

`dendrite_structural_organization_vectors.csv` — одна строка соответствует одному дендритному фрагменту, то есть объекту `Dendrite` / `DendriteBranch`.

`neuron_structural_network_vectors.csv` — одна строка соответствует одному нейрону, то есть объекту `Neuron`.

Для MICrONS-данных эти два уровня можно запускать независимо или вместе. `Neuron.run_full_analysis(mode="network")` строит только сетевой вектор нейрона, `mode="branches"` строит только векторы отдельных branch-фрагментов через `DendriteBranch`, а `mode="both"` выполняет оба анализа на одних и тех же уже загруженных мешах, скелетах и точках крепления шипиков.

## Итоговый вектор дендрита

### Этап 0 — идентификация дендритного фрагмента

- `Name` — имя дендритного фрагмента. Используется как идентификатор строки.

- `Type` — технический тип, извлекаемый из первых символов имени дендрита `self.name[:2]`. Это не полноценная биологическая разметка, а служебное поле.

- `n_spines` — число шипиков на данном дендритном фрагменте:

\[
n = |S|.
\]

### Этап 1 — базовые геометрические метрики дендрита

- `dendrite_Volume` — объём дендритного меша \(V_D\). Если прямой расчёт объёма по мешу невозможен, может использоваться приближённый fallback.

- `dendrite_Length` — длина дендритного фрагмента \(L_D\). Предпочтительно берётся из зарегистрированного скелета; если скелета нет, оценивается по геометрии меша.

- `dendrite_Radius` — эффективный радиус дендрита \(R_D\), вычисляемый из цилиндрической аппроксимации:

\[
R_D=\sqrt{\frac{V_D}{\pi L_D}}.
\]

Эта метрика не означает, что дендрит считается идеальным цилиндром. Она задаёт грубый геометрический масштаб фрагмента.

### Этап 2 — плотность и общее распределение шипиков

- `density_pair_distance_profile_entropy` — энтропия профиля попарных расстояний между шипиками. Сначала строится описательный профиль

\[
h(r)=\frac{1}{n}\sum_{i\neq j}\mathbf{1}\{r\leq d_{ij}<r+dr\},
\]

после чего значения профиля нормируются:

\[
p_k=\frac{h(r_k)}{\sum_l h(r_l)}.
\]

Энтропия вычисляется как

\[
H=-\sum_k p_k\log p_k.
\]

Если сумма значений профиля равна нулю, энтропия считается равной нулю. Чем выше энтропия, тем более разнообразно распределены расстояния между парами шипиков по масштабам.

- `spatial_nearest_neighbor_mean` — среднее расстояние до ближайшего соседа:

\[
\frac{1}{n}\sum_{i=1}^{n} d_{i(1)},
\]

где \(d_{i(1)}=\min_{j\neq i}d_{ij}\).

- `spatial_nearest_neighbor_median` — медиана расстояний до ближайшего соседа.

- `spatial_nearest_neighbor_std` — стандартное отклонение расстояний до ближайшего соседа.

- `spatial_nearest_neighbor_cv` — коэффициент вариации расстояний до ближайшего соседа:

\[
CV_{NN}=
\frac{\operatorname{sd}(d_{i(1)})}
{\operatorname{mean}(d_{i(1)})}.
\]

Высокое значение указывает на неоднородность локальной плотности шипиков.

- `spatial_nearest_neighbor_q10` — 10-й перцентиль распределения расстояний до ближайшего соседа.

- `spatial_nearest_neighbor_q25` — 25-й перцентиль распределения расстояний до ближайшего соседа.

- `spatial_nearest_neighbor_q75` — 75-й перцентиль распределения расстояний до ближайшего соседа.

- `spatial_nearest_neighbor_q90` — 90-й перцентиль распределения расстояний до ближайшего соседа.

- `spatial_mean_pair_distance` — среднее расстояние по всем парам шипиков \(i<j\).

- `spatial_median_pair_distance` — медиана всех попарных расстояний.

- `spatial_pair_distance_std` — стандартное отклонение всех попарных расстояний.

- `spatial_pair_distance_cv` — коэффициент вариации всех попарных расстояний:

\[
CV_{\mathrm{pair}}=
\frac{\operatorname{sd}(d_{ij}:i<j)}
{\operatorname{mean}(d_{ij}:i<j)}.
\]

Эта метрика показывает, насколько неоднороден общий масштаб взаимного расположения всех пар шипиков на дендритном фрагменте.

- `spatial_pair_distance_q10` — 10-й перцентиль распределения попарных расстояний.

- `spatial_pair_distance_q25` — 25-й перцентиль распределения попарных расстояний.

- `spatial_pair_distance_q75` — 75-й перцентиль распределения попарных расстояний.

- `spatial_pair_distance_q90` — 90-й перцентиль распределения попарных расстояний.

### Этап 3 — анализ локальных окрестностей

- `neighborhood_local_radius` — радиус локальной окрестности \(\varepsilon\), используемый для построения порогового графа соседства.

- `neighborhood_close_pair_fraction` — доля близких пар шипиков на том же радиусе \(\varepsilon\), который используется для локальных окрестностей:

\[
F_\varepsilon=
\frac{
\#\{(i,j):i<j,\ d_{ij}\leq\varepsilon\}
}
{
\#\{(i,j):i<j\}
}.
\]

Если уже посчитан положительный `dbscan_eps`, используется он; иначе \(\varepsilon\) выбирается как 75-й перцентиль расстояний до третьего ближайшего соседа:

\[
\varepsilon=Q_{0.75}\left(\{d_{i(3)}\}_{i=1}^{n}\right).
\]

- `neighborhood_local_neighbor_count_mean` — среднее число соседей в локальной окрестности. Для шипика \(s_i\) число соседей равно

\[
\rho_i=\sum_{j\neq i}\mathbf{1}\{d_{ij}\leq\varepsilon\}.
\]

Метрика сохраняет среднее значение \(\rho_i\) по всем шипикам.

- `neighborhood_local_neighbor_count_max` — максимальное число соседей среди всех шипиков.

- `neighborhood_local_isolated_fraction` — доля шипиков, не имеющих соседей в радиусе \(\varepsilon\):

\[
\frac{\#\{i:\rho_i=0\}}{n}.
\]

- `neighborhood_threshold_graph_edges` — число рёбер в пороговом графе \(G_\varepsilon\), где ребро между двумя шипиками проводится при \(d_{ij}\leq\varepsilon\).

- `neighborhood_threshold_graph_components` — число компонент связности в пороговом графе \(G_\varepsilon\).

- `neighborhood_threshold_graph_largest_component` — размер крупнейшей компоненты связности в \(G_\varepsilon\).

### Этап 4 — морфологическая автокорреляция

Для каждой доступной числовой морфологической метрики шипика создаётся отдельный набор колонок. В текущей облегчённой конфигурации это обычно `Volume` и `Length`.

Шаблон колонок:

- `autocorr_<metric>_local_radius` — радиус локального соседства \(\varepsilon\), по которому строилась матрица весов.

- `autocorr_<metric>_moran_i` — глобальный индекс Морана \(I\) для морфологической метрики:

\[
I=
\frac{n}{W}
\frac{
\sum_{i,j}w_{ij}(x_i-\bar{x})(x_j-\bar{x})
}
{
\sum_i(x_i-\bar{x})^2
},
\qquad
W=\sum_{i,j}w_{ij}.
\]

Положительные значения означают, что рядом чаще находятся шипики с похожими значениями признака. Отрицательные значения означают соседство контрастных значений.

- `autocorr_<metric>_moran_i_permutation_p` — перестановочное \(p\)-значение для глобального индекса Морана. Значения признака случайно перемешиваются между фиксированными позициями шипиков, после чего индекс пересчитывается.

- `autocorr_<metric>_geary_c` — коэффициент Гири \(C\):

\[
C=
\frac{n-1}{2W}
\frac{
\sum_{i,j}w_{ij}(x_i-x_j)^2
}
{
\sum_i(x_i-\bar{x})^2
}.
\]

Значения \(C<1\) соответствуют положительной автокорреляции, \(C\approx1\) отсутствию выраженной структуры, \(C>1\) соседству непохожих значений.

- `autocorr_<metric>_geary_c_permutation_p` — перестановочное \(p\)-значение для коэффициента Гири. В коде проверяется отклонение \(C\) от 1.

- `autocorr_<metric>_neighbor_spearman_r` — коэффициент соседской ранговой корреляции Спирмена. Для каждого шипика сравнивается собственное значение признака \(x_i\) и среднее значение этого признака среди соседей:

\[
\bar{x}_{N(i)}=
\frac{1}{|N_\varepsilon(i)|}
\sum_{j\in N_\varepsilon(i)}x_j.
\]

Затем считается корреляция Спирмена между векторами \((x_i)\) и \((\bar{x}_{N(i)})\).

- `autocorr_<metric>_neighbor_spearman_p` — обычное \(p\)-значение теста значимости корреляции Спирмена.

- `autocorr_<metric>_neighbor_spearman_permutation_p` — перестановочное \(p\)-значение для соседской корреляции Спирмена.

- `autocorr_<metric>_n_permutations` — число перестановок, использованных для оценки перестановочных \(p\)-значений.

### Этап 5 — пространственная кластеризация DBSCAN

- `spatial_dbscan_eps` — радиус DBSCAN \(\varepsilon\).

- `spatial_dbscan_min_samples` — минимальное число объектов в \(\varepsilon\)-окрестности, необходимое для формирования плотной области. В актуальной конфигурации обычно равно 3.

- `spatial_dbscan_noise_fraction` — доля шипиков, помеченных DBSCAN как noise:

\[
q_{\mathrm{noise}}=
\frac{\#\{i:c_i=-1\}}{n}.
\]

- `spatial_n_dbscan_clusters` — число найденных DBSCAN-кластеров без учёта noise-точек.

- `spatial_mean_dbscan_cluster_size` — средний размер DBSCAN-кластера:

\[
\frac{1}{K}\sum_{k=1}^{K}|C_k|.
\]

- `spatial_max_dbscan_cluster_size` — размер крупнейшего DBSCAN-кластера:

\[
\max_k |C_k|.
\]

Подробные признаки каждого отдельного DBSCAN-кластера сохраняются отдельно в `spatial_morphology_clusters.csv` и не входят в итоговый ML-вектор.

### Этап 6 — сравнение кластеризованных и изолированных шипиков

Для каждой доступной числовой морфологической метрики создаются колонки с шаблоном `test_clustered_vs_isolated_<metric>_*`.

Абсолютные числа кластеризованных и изолированных шипиков не включаются в итоговый ML-вектор, поскольку эта информация сильно зависит от общего числа шипиков на дендрите. Для нормированного описания используется `spatial_dbscan_noise_fraction`. При необходимости абсолютное число изолированных шипиков можно восстановить из `n_spines` и `spatial_dbscan_noise_fraction`, а детальные счётчики остаются в таблице `spatial_morphology_tests.csv`.

- `test_clustered_vs_isolated_<metric>_clustered_mean` — среднее значение морфологической метрики среди кластеризованных шипиков.

- `test_clustered_vs_isolated_<metric>_isolated_mean` — среднее значение морфологической метрики среди изолированных шипиков.

- `test_clustered_vs_isolated_<metric>_clustered_median` — медиана морфологической метрики среди кластеризованных шипиков.

- `test_clustered_vs_isolated_<metric>_isolated_median` — медиана морфологической метрики среди изолированных шипиков.

- `test_clustered_vs_isolated_<metric>_clustered_std` — стандартное отклонение морфологической метрики среди кластеризованных шипиков.

- `test_clustered_vs_isolated_<metric>_isolated_std` — стандартное отклонение морфологической метрики среди изолированных шипиков.

- `test_clustered_vs_isolated_<metric>_clustered_cv` — коэффициент вариации морфологической метрики среди кластеризованных шипиков:

\[
CV_{\mathrm{clustered}}=
\frac{\operatorname{sd}(x_{\mathrm{clustered}})}
{\operatorname{mean}(x_{\mathrm{clustered}})}.
\]

- `test_clustered_vs_isolated_<metric>_isolated_cv` — коэффициент вариации морфологической метрики среди изолированных шипиков:

\[
CV_{\mathrm{isolated}}=
\frac{\operatorname{sd}(x_{\mathrm{isolated}})}
{\operatorname{mean}(x_{\mathrm{isolated}})}.
\]

- `test_clustered_vs_isolated_<metric>_mannwhitney_statistic` — статистика теста Манна--Уитни. Тест проверяет, отличаются ли распределения признака в двух группах: кластеризованные шипики против изолированных.

- `test_clustered_vs_isolated_<metric>_mannwhitney_p` — \(p\)-значение теста Манна--Уитни.

- `test_clustered_vs_isolated_<metric>_brunnermunzel_statistic` — статистика теста Бруннера--Мунцеля. Этот тест также сравнивает две группы, но устойчивее к различию дисперсий и форм распределений.

- `test_clustered_vs_isolated_<metric>_brunnermunzel_p` — \(p\)-значение теста Бруннера--Мунцеля.

- `test_clustered_vs_isolated_<metric>_cliffs_delta` — размер эффекта Cliff's delta:

\[
\delta=
\frac{
\#\{(x,y):x>y\}
-
\#\{(x,y):x<y\}
}
{n_xn_y},
\]

где \(x\) пробегает значения признака среди кластеризованных шипиков, а \(y\) среди изолированных. Если \(\delta>0\), признак чаще выше у кластеризованных шипиков; если \(\delta<0\), чаще выше у изолированных; если \(\delta\approx0\), выраженного эффекта нет.

### Этап 7 — графовый анализ пространственной организации

- `graph_average_clustering` — средний коэффициент кластеризации графа пространственных связей между шипиками.

- `graph_mean_cluster_size` — средний размер найденных графовых сообществ.

- `graph_characteristic_extent` — характерная пространственная протяжённость графовых сообществ.

- `graph_modularity` — модулярность разбиения графа на сообщества. Чем выше модулярность, тем сильнее граф распадается на относительно плотные внутренние группы со сравнительно редкими связями между ними.

## Итоговый вектор всей сети нейрона

### Этап 0 — идентификация нейрона

- `neuron_id` — идентификатор нейрона, обычно имя папки нейрона.

### Этап 1 — топология и длина дендритной сети

- `network_branch_node_linear_density` — линейная плотность узлов ветвления на дендритной сети:

\[
\rho_{\mathrm{branch}}=
\frac{n_{\mathrm{branch\ nodes}}}{|L|}.
\]

- `network_terminal_node_linear_density` — линейная плотность терминальных узлов на дендритной сети:

\[
\rho_{\mathrm{terminal}}=
\frac{n_{\mathrm{terminal\ nodes}}}{|L|}.
\]

Абсолютные `network_n_branch_nodes` и `network_n_terminal_nodes` сохраняются в `neuron_metadata.csv`, а в ML-вектор включаются нормированные версии.

### Этап 2 — линейная плотность шипиков

- `network_spine_linear_density` — линейная плотность шипиков на дендритной сети:

\[
\rho_L=
\frac{n_{\mathrm{projected}}}{|L|}.
\]

### Этап 3 — отдельные характеристики апикальных и базальных частей

- `apical_spine_linear_density` — линейная плотность шипиков на апикальной части дендритной сети:

\[
\rho_{\mathrm{spine,apical}}=
\frac{n_{\mathrm{spines,apical}}}{|L_{\mathrm{apical}}|}.
\]

- `basal_spine_linear_density` — линейная плотность шипиков на базальной части дендритной сети:

\[
\rho_{\mathrm{spine,basal}}=
\frac{n_{\mathrm{spines,basal}}}{|L_{\mathrm{basal}}|}.
\]

- `apical_branch_node_linear_density` — линейная плотность узлов ветвления на апикальной части сети.

- `basal_branch_node_linear_density` — линейная плотность узлов ветвления на базальной части сети.

- `apical_terminal_node_linear_density` — линейная плотность терминальных узлов на апикальной части сети.

- `basal_terminal_node_linear_density` — линейная плотность терминальных узлов на базальной части сети.

Абсолютные количества апикальных и базальных лимбов/branch-фрагментов сохраняются в `neuron_metadata.csv`. В ML-вектор включаются плотности, поскольку они менее привязаны к размеру реконструкции и информативнее описывают организацию шипиков и топологии внутри типов дендритов.

### Этап 4 — метрики сомы

- `soma_volume` — объём меша сомы. Если прямой объём недоступен, может использоваться объём выпуклой оболочки как приближение.

- `soma_surface_area` — площадь поверхности меша сомы.

Bounding box сомы (`soma_bbox_x`, `soma_bbox_y`, `soma_bbox_z`) не сохраняется ни в ML-вектор, ни в metadata-таблицу, поскольку эти величины зависят от ориентации объекта в координатах и дают слабую дополнительную информацию при наличии объёма и площади поверхности.

### Этап 5 — проверка зависимости интенсивности от расстояния до сомы

- `intensity_cdf_statistic` — статистика CDF/KS-теста, сравнивающего распределение расстояний до сомы у шипиков с распределением расстояний до сомы у равномерно выбранных точек дендритной сети.

- `intensity_cdf_p_value` — \(p\)-значение CDF/KS-теста. Малое значение указывает, что интенсивность шипиков зависит от расстояния до сомы.

- `intensity_lr_statistic` — likelihood-ratio statistic для сравнения постоянной пуассоновской интенсивности и модели с линейной зависимостью от расстояния до сомы.

- `intensity_lr_p_value` — \(p\)-значение likelihood-ratio теста.

### Этап 6 — неоднородная пуассоновская модель интенсивности

Эти поля появляются, если модель удалось подогнать.

- `poisson_log_likelihood` — лог-правдоподобие подогнанной неоднородной пуассоновской модели:

\[
\ell(\theta)=
\sum_{i=1}^{n}\log\lambda(x_i)
-
\int_L \lambda(u)\,du.
\]

- `poisson_aic` — информационный критерий Акаике:

\[
AIC=-2\ell+2k,
\]

где \(k\) — число параметров модели.

- `poisson_bic` — байесовский информационный критерий:

\[
BIC=-2\ell+k\log n.
\]

- `poisson_coef_<covariate>` — коэффициент \(\theta\) при соответствующей ковариате в модели

\[
\lambda(u)=\exp(\theta^\top z(u)).
\]

В стандартной конфигурации появляются поля `poisson_coef_intercept`, `poisson_coef_distance_to_soma`, `poisson_coef_distance_to_soma_squared`.

- `poisson_se_<covariate>` — стандартная ошибка коэффициента при соответствующей ковариате.

Флаг сходимости оптимизации `poisson_converged` сохраняется в `neuron_metadata.csv` как диагностическая информация, но не входит в ML-вектор.

### Этап 7 — сетевая функция Рипли \(K_L\)

Эти поля появляются, если удалось выполнить K-анализ.

- `k_p_value` — \(p\)-значение Monte Carlo проверки того, насколько сильно наблюдаемая K-кривая отклоняется от K-кривой, ожидаемой при выбранной null-модели.

- `k_mean_deviation` — среднее отклонение наблюдаемой K-кривой от ожидаемой:

\[
\operatorname{mean}_r\left(K_{\mathrm{obs}}(r)-K_{\mathrm{exp}}(r)\right).
\]

- `k_max_positive_deviation` — максимальное положительное отклонение \(K_{\mathrm{obs}}(r)-K_{\mathrm{exp}}(r)\). Большое положительное значение соответствует кластеризации на некотором масштабе.

- `k_max_negative_deviation` — максимальное отрицательное отклонение:

\[
\min_r \left(K_{\mathrm{obs}}(r)-K_{\mathrm{exp}}(r)\right).
\]

Сильно отрицательное значение соответствует регулярности или пространственному отталкиванию на некотором масштабе: у реальных шипиков меньше соседей, чем ожидалось по null-модели.

- `k_max_abs_deviation` — максимальное абсолютное отклонение:

\[
\max_r |K_{\mathrm{obs}}(r)-K_{\mathrm{exp}}(r)|.
\]

- `k_r_at_max_positive_deviation` — значение радиуса \(r\), на котором достигается максимальное положительное отклонение.

- `k_r_at_max_negative_deviation` — значение радиуса \(r\), на котором достигается максимальное отрицательное отклонение.

- `k_r_at_max_abs_deviation` — значение радиуса \(r\), на котором достигается максимальное абсолютное отклонение.

Для апикальной и базальной частей дополнительно создаются аналогичные поля с префиксами `apical_k_*` и `basal_k_*`, если в соответствующей части есть как минимум три спроецированных шипика и ненулевая длина сети:

- `<type>_k_p_value` — \(p\)-значение Monte Carlo проверки отклонения K-кривой соответствующей части сети от K-кривой, ожидаемой при выбранной null-модели.

- `<type>_k_mean_deviation` — среднее отклонение \(K_{\mathrm{obs}}(r)-K_{\mathrm{exp}}(r)\) внутри соответствующей части.

- `<type>_k_max_positive_deviation` — максимальное положительное отклонение, то есть strongest clustering summary для соответствующей части.

- `<type>_k_max_negative_deviation` — максимальное отрицательное отклонение, то есть strongest regularity summary для соответствующей части.

- `<type>_k_max_abs_deviation` — максимальное абсолютное отклонение.

- `<type>_k_r_at_max_positive_deviation` — радиус, на котором достигается максимальное положительное отклонение.

- `<type>_k_r_at_max_negative_deviation` — радиус, на котором достигается максимальное отрицательное отклонение.

- `<type>_k_r_at_max_abs_deviation` — радиус, на котором достигается максимальное абсолютное отклонение.

Здесь `<type>` принимает значения `apical` или `basal`. Эти признаки описывают пространственную организацию шипиков отдельно на апикальной и базальной частях без выполнения полноценного replicated point pattern comparison между группами.

Метод расчёта K-функции `k_method` сохраняется в `neuron_metadata.csv`. Массивы `k_observed_values`, `k_expected_values` и `k_r_values` не включаются ни в ML-вектор, ни в metadata-таблицу: полная K-кривая сохраняется отдельно в файлах `ripley_k_network.csv`, `ripley_k_network_apical.csv` и `ripley_k_network_basal.csv` для каждого нейрона, если соответствующий анализ был выполнен.

## Metadata-таблица анализа всей сети нейрона

Файл `neuron_metadata.csv` сохраняется рядом с `neuron_structural_network_vectors.csv` и содержит технические, размерные и диагностические поля, которые полезны для контроля качества, но не используются как основные ML-признаки.

- `neuron_id` — идентификатор нейрона.

- `n_limbs` — число лимбов, найденных в папке нейрона.

- `n_branches` — число branch-папок со шипиками, включённых в анализ.

- `n_spines_total` — общее число шипиков, для которых были получены точки крепления.

- `n_spines_projected` — число шипиков, успешно спроецированных на дендритный граф.

- `n_spines_unassigned` — число шипиков, которые не удалось сопоставить с рёбрами графа при заданном пороге расстояния.

- `projection_success_rate` — доля успешно спроецированных шипиков; сохраняется как QC-метрика, но не входит в ML-вектор, поскольку характеризует качество сопоставления данных с графом, а не биологические свойства нейрона.

- `network_total_length` — суммарная длина дендритного графа.

- `network_n_nodes` — число узлов в графе дендритной сети.

- `network_n_edges` — число рёбер в графе дендритной сети.

- `network_n_branch_nodes` — абсолютное число узлов ветвления.

- `network_n_terminal_nodes` — абсолютное число терминальных узлов.

- `network_apical_length` — суммарная длина апикальной части графа, используемая как знаменатель для апикальных линейных плотностей.

- `network_basal_length` — суммарная длина базальной части графа, используемая как знаменатель для базальных линейных плотностей.

- `network_unknown_length` — суммарная длина участков графа без уверенной апикальной/базальной разметки.

- `n_apical_limbs` — число лимбов с типом `apical`.

- `n_basal_limbs` — число лимбов с типом `basal`.

- `n_unknown_limbs` — число лимбов без апикальной/базальной разметки.

- `n_apical_branches` — число branch-фрагментов с типом `apical`.

- `n_basal_branches` — число branch-фрагментов с типом `basal`.

- `n_unknown_branches` — число branch-фрагментов без апикальной/базальной разметки.

- `limb_length_mean`, `limb_length_median`, `limb_length_std` — описательные статистики длин лимбов.

- `branch_length_mean`, `branch_length_median`, `branch_length_std` — описательные статистики длин branch-фрагментов.

- `branch_spine_count_mean`, `branch_spine_count_median`, `branch_spine_count_std` — описательные статистики числа шипиков на branch-фрагмент.

- `poisson_converged` — диагностический флаг успешной сходимости неоднородной пуассоновской модели.

- `k_method` — метод расчёта сетевой K-функции.
